# The new "Reviewer Reminded" label shows as a raw key in every language but English

Regression, minor. Found in a PR review of the unmerged
pkp/pkp-lib#13346 and pkp/ui-library#987 (issue pkp/pkp-lib#13263;
ojs#5835 bumps the pointers). Driven on OJS at the PR heads (lib/pkp
`26a5efcb74`, ui-library `ad0fdd33`), each merged locally onto the
current tips (lib/pkp `25182919bf`, ui-library `1afd40a9`). OMP carries
the same code; OPS has no review stage. Recorded in U27 as
[A34](../specs/U27-reviewer-assignment-and-management.md#a34) on the
companion branch `i13263`, and in the `docs/tracking/ci-triage.md`
companion row. Temporary: delete once acted on.

## Summary

The new key `editor.review.reviewerReminded` exists only in
`locale/en/editor.po`. In every other interface language, History and
Review Details show "##editor.review.reviewerReminded##" on the reminder
line. In French that line read "Rappel" before this change. All the other
new labels are already translated. This is the usual lag before
translations catch up, reported because a translated screen now shows a
raw key.

The same review also turned up two readings that were ruled intended on
2026-09-24 (@jarda.kotesovec):

- **U27 A33 and A27.** "Revert Decision" takes back only "Mark as
  Complete". The thank was already sent, so it stands. A review that is
  marked complete again therefore shows "Reviewer Thanked: {first thank}"
  in Review Details.
- **U27 A35.** History drops the "Reviewer Thanked" line after a revert.
  History shows only the dates tracked today, and an event log will
  replace it later.

Everything else matches the issue on OJS, in every state: invited,
reminded, declined, accepted, submitted, completed, thanked, and reverted
from complete. Both surfaces show the new labels, and History uses the
"{Label}: {date}" form. No request failed and the console had no errors.

## Steps to reproduce

Preconditions: a fresh OJS install. A journal with Français (Canada) as
an interface language. A submission in review, with a reviewer who has
not answered the request.

1. As the editor, send the reviewer a reminder ("Send Reminder").
2. Switch the interface to Français.
3. Open the reviewer row's "Historique" (History), then its Review
   Details.

**Expected:** the reminder line carries a French label, as "Rappel" did
before.

**Observed** (2026-09-24):

- History: `Demande envoyée : 2026-09-24 06:15 AM` /
  `##editor.review.reviewerReminded## : 2026-09-24 06:15 AM`.
- Review Details: `##editor.review.reviewerReminded## : 2026-09-24
  06:15 a.m.`
- `pkp.localeKeys['editor.review.reviewerReminded']` is
  `##editor.review.reviewerReminded##`.

## Cause

`editor.review.reviewerReminded` is added to `locale/en/editor.po` only,
and `Locale::translate` has no English fallback.

## Proposed fix

A proposal; the team decides. Nothing needs to change before the merge
if the team accepts the translation lag. Otherwise, reuse an
already-translated key for this label until Weblate catches up.
