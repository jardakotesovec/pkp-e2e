plugin's `Schema::get::doi` hook out of the `getEnabled()` check in
`register()`, as crossref-ojs `main` already has it (`6970a0b894`), so
the command-line job tool, which loads the generic plugins with no
context, gets the agency's message fields in the DOI schema.

with `cli-deposit.php`; OJS and OPS, a fresh install with
`[queues] job_runner = Off` and the test config's dead-port `[proxy]`)

1. A new journal (or server) with DOIs on for publications, the agency
   plugin enabled with a username and password, and chosen as the
   Registration Agency; one published work.

   queues, with `markSubmitted`), then
   `php lib/pkp/tools/jobs.php work --stop-when-empty=1`.
