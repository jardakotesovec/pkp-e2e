## 1. Every edit of an anonymous contributor logs a PHP warning on `main` (low)

**Steps** (OJS `main` with pkp-lib#13879, a fresh install; the same code in OMP and OPS)

1. As the journal manager, add an anonymous contributor to a submission
   (`POST …/contributors` with `contributorType: ANONYMOUS`, an email and
   a country).
2. Edit it: `PUT …/contributors/{id}` with `{"country": "DE"}`, or with
   `{"contributorType": "ANONYMOUS", "country": "FR"}` as the contributor
   form sends it, or switch a person who has an affiliation to Anonymous
   (`{"contributorType": "ANONYMOUS", …}`).
   Expected: 200, the change saved, nothing in the PHP error log (the
   issue's expected result; the base logs nothing for the typed edits).
   Observed: 200 and the change saved (the switched person's affiliation
   is removed, as before), but each request logs
   `PHP Warning: foreach() argument must be of type array|object, null given in …/api/v1/submissions/PKPSubmissionController.php on line 1961`.

**Cause** `api/v1/submissions/PKPSubmissionController.php:1959-1961`:
for an anonymous contributor (sent or stored type),
`removeIrrelevantContributorTypeData()` sets `$params['affiliations']`
to `null`, so `array_key_exists('affiliations', $params)` is true and the
new branch runs `foreach` on `null`; the base's `?? []` covered it.

**Fix** `foreach ($params['affiliations'] ?? [] as $position => $affiliationParam)`
inside the new `if`; tried on OJS at the head: no warning on any step,
the switch to Anonymous still removes the affiliations, and the person,
organization and `[]` cases unchanged
(`shared/playwright/checks/sync/pkp-lib-13879/fix-anonymous-affiliations.diff`,
check `shared/playwright/checks/sync/pkp-lib-13879/edit-without-type.js`,
`PROBE_RUN=fix`). `stable-3_5_0` has no contributor types and is not
affected.
