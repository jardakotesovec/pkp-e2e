## 1. On 3.4 and 3.3 the tool still warns for a plugin that ships its email texts the deprecated way (question)

**Steps** (OJS 3.4 or 3.3, read in the code, not driven: no bundled
or PKP plugin uses the deprecated method)

1. Take a plugin that returns a file from the deprecated
   `getInstallEmailTemplateDataFile()` (pkp/pkp-lib#5461), such as the
   old langsci/vgWort or Billplz-for-OJS-3 plugins, and run
   `php lib/pkp/tools/installPluginVersion.php <plugin>/version.xml`.
   Expected: the template texts installed, no warning. Observed (code):
   `PHP Warning: foreach() argument must be of type array|object, null given`
   and no texts, at the base and at the PR heads alike.

**Cause** `classes/plugins/Plugin.php:630` (3.4) and
`classes/plugins/Plugin.inc.php:628` (3.3), at the PR heads, `installEmailTemplateData()`:
it still loops over `$installer->installedLocales`, which the tool leaves
null; the PRs move only `installEmailTemplates()` to the site's
installed locales. Round 1's tool change (#13704, #13705) covered both
callbacks.

**Fix** Either the same change in `installEmailTemplateData()`, or
keep round 1's one line in `tools/installPluginVersion.php` on 3.4 and
3.3 beside the new PRs. Leaning to leaving it: the method has been
deprecated since 3.3, and no bundled or PKP plugin uses it. Not tried.
