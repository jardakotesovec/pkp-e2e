# Friction — what made an agent's task harder than it needed to be

Any agent may append here, at the end of its task, when something cost it
calls, time or retries that a better brief, doc, kit, seed or fixture would
have saved. Nobody reads this file mid-feature. The maintenance session
folds it on a quiet day (MAINTENANCE "The daily session"), and the fold is
a critical read, not a transcription: one agent's struggle is not a
process defect. A row earns a change only when all three hold: a third
feature would meet the same thing (a shared screen, the kit, a seeding
key); the docs do not already say it (grep `patterns.md`, `scenarios.md`
and `seed-facts.md` first; most rows of the first fold asked for lines
that existed); and it is neither general Playwright knowledge nor a fact
about one feature's own screen (that lives in the feature's screen notes
and its kept check scripts). What passes goes as a kit or helper change,
a clause on an existing `patterns.md` entry, or one sentence in the
seeding docs; never a new section, never a per-screen catalogue. A
harness key a row asks for is listed under scenarios.md "Field shapes
not built yet", not built. Every row is then deleted, acted on or not;
git keeps it.

One line per entry, appended at the end, in this shape:

`YYYY-MM-DD · U<nn> · <role and agent id> · <what cost you calls, time or retries> · <what would have helped>`

Facts only, the same quarantine as everywhere else (nothing
security-shaped, no credentials). A rule you disagree with is fine to name;
say what it cost.
