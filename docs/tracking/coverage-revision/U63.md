- **Rules 26 and 27, the export side**: lean S6, which exports from A, with the two accounts added to its Given; or the new scenario that holds Rule 24b's ended roles.
- **The DOAJ daily deposit (Rule 43)**: a second journal and the scheduled task; lean a scenario of its own {OJS}, since S9 registers one journal's articles by hand. The writer checks scenarios.md for a key that runs the scheduled task (the U45 and U63 suites run `depositDois` style tasks through the `_test` API); with none, it is named for a harness agent (RUNBOOK step 4) or stays Planned under "No seed" with the reason.
